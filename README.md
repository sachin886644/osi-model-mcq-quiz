# OSI Model MCQ Quiz

Interactive multiple-choice quiz on the **OSI 7-layer model**.

- 15 questions covering layers, PDUs, protocols, and devices
- Instant feedback and short explanations
- Score + review at the end
- Pure HTML, CSS, and JavaScript — no build step

## Live site

https://osi-model-mcq-quiz.netlify.app

## GitHub

https://github.com/sachin886644/osi-model-mcq-quiz

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Stack

HTML + CSS + vanilla JavaScript.
